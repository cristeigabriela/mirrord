Fixed the Windows `pitm` layer extraction reusing a stale layer DLL after the mirrord binary was upgraded: the layer was cached under a fixed temp filename and never refreshed, so a new binary loaded the old layer and failed to decode its config ("Decoding resolved config failed: invalid type: null, expected a boolean"). The extracted layer is now keyed by build metadata (version + size) so a new binary always extracts and loads its own layer.
